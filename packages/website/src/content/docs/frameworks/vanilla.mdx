You can use `TegakiEngine` directly with plain JavaScript or TypeScript, without a framework.

## Basic example

```html
<div id="tegaki" style="font-size: 48px"></div>

<script type="module">
  import { TegakiEngine } from 'tegaki/core';
  import bundle from 'tegaki/fonts/caveat';

  const container = document.getElementById('tegaki');

  const engine = new TegakiEngine(container, {
    text: 'Hello World',
    font: bundle,
    time: { mode: 'uncontrolled', speed: 1, loop: true },
  });
</script>
```

The engine creates its DOM elements inside the container.

## Updating options

Call `update()` to change text, font, time, or plugins at any time:

```js
import { glowPlugin } from 'tegaki/core';

engine.update({ text: 'New text' });

engine.update({
  plugins: [glowPlugin({ radius: 0.1, color: '#00ccff' })],
});
```

## Controlled time

Pass a number to `time` and update it on each frame:

```js
const engine = new TegakiEngine(container, {
  text: 'Controlled',
  font: bundle,
  time: 0,
});

let t = 0;
function animate() {
  t += 0.016;
  engine.update({ time: t });
  requestAnimationFrame(animate);
}
animate();
```

## Plugins

Glows, gradients, tapered ends, wobble and the rest are plugins. Import the factories from `tegaki/core` and pass the plugins in a list:

```js
import { glowPlugin, strokeGradientPlugin, TegakiEngine } from 'tegaki/core';

const engine = new TegakiEngine(container, {
  text: 'Glowing rainbow',
  font: bundle,
  time: { mode: 'uncontrolled', speed: 1, loop: true },
  plugins: [strokeGradientPlugin(), glowPlugin({ radius: 0.1, color: '#00ccff' })],
});
```

/>

Register a factory and `plugins` can name it, with or without options. That's handy when the list comes from data (a JSON config, a `data-` attribute):

```js
TegakiEngine.registerPlugin(glowPlugin, strokeGradientPlugin);

engine.update({ plugins: ['strokeGradient', ['glow', { radius: 0.1, color: '#00ccff' }]] });
```

See [Style plugins](/api/renderer/#style-plugins) and [Naming plugins](/api/renderer/#naming-plugins). The `pressure` option (`0` to `1`, default `1`) sets how much the ink's width follows the pen's pressure.

## Cleanup

Call `destroy()` when you're done to remove event listeners and stop the animation loop:

```js
engine.destroy();
```

## Font registration

Register bundles globally so you can reference them by name:

```js
import { TegakiEngine } from 'tegaki/core';
import caveat from 'tegaki/fonts/caveat';

TegakiEngine.registerBundle(caveat);

// Later, anywhere in your app:
const engine = new TegakiEngine(container, {
  text: 'Hello',
  font: 'Caveat', // resolved from the registry
});
```

## Pre-rendering (SSR)

Use `TegakiEngine.renderElements()` to produce the element tree on the server, then adopt it on the client:

```js
import { TegakiEngine } from 'tegaki/core';

// Server: render to HTML string
const html = TegakiEngine.renderElements(
  { text: 'Hello', font: bundle },
  (tag, props, ...children) => {
    // your HTML string builder
  },
);

// Client: adopt pre-rendered DOM
const engine = new TegakiEngine(container, { adopt: true, text: 'Hello', font: bundle });
```

This is what all framework adapters use internally.
